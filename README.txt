Godot EngineとAIでデザイナーでもゲームが作れる！

index.html または open-slides.cmd を開いてください。
19枚／16:9／1920×1080基準。2ページ目に結論スライドを追加。ネットなしでもスライド本体は表示できます。

操作：← →、PageUp PageDown、Space、Home、End
全画面：画面右下の全画面ボタン、またはF。解除はEsc。
最後から次へ進むと先頭へ戻ります。

guide.html：接続設定の補足、制作記録の整理、出典（確認日2026-10-01）
prompts.txt：学生がコピーできる確認・制作依頼・不具合相談の例文
assets：実際のGodotプロジェクトのゲーム画像

HTML、CSS、JavaScript、assetsを同じフォルダー構成で保管してください。
Godot本体や元のゲーム、MCP設定はこの配布物に含まれません。
この資料作成では元のゲームや接続設定は変更していません。
