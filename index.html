03 / 用意するもの

まず基本。MCPを選ぶなら追加。

最初から必要

ゲームを作る基本セット

  • Windows版のCodexを起動・ログイン
  • Godotを用意・起動
    この実例は4.6.3の通常版（C#不使用）
  • 自分のゲームの保存先フォルダー
今回のMCP方式で必要

AIから道具を呼ぶ準備

  • Node.js と npm
    MCPを動かす土台と、入れるための道具
  • Coding-Solo製 Godot MCP

Godotは無料。Codexの利用条件・利用枠は別に確認します。

提供元のNode.js条件は18以上。授業ではサポート中のLTS版を選ぶ。料金は一律に無料とは案内しない。

Godot

今回の外部製ツール

Coding-Solo / godot-mcp
GodotやOpenAIの公式標準機能ではありません。

実際の制作には2つの経路

応答：確認プログラム → MCP → Godot
制作：Codex → ファイル編集 → Godot起動

09 / うまくいかないとき

上から順に、場所を確かめる。

1 保存したフォルダーは合っている？

2 そこに project.godot はある？

3 GODOT_PATH は実在する.exe？

4 MCPの設定と応答を確認できる？

5 変更した設定を読み込み直した？

不具合相談の例文

Godotを開く操作で止まりました。
保存先は【自分のパス】です。
期待したことは【内容】、
実際には【起きたこと】です。
エラー全文と画面を添付します。
原因を調べ、直す順番を教えてください。

再読み込みが必要なのは、変更を反映するとき。エラーの原因も確かめよう。

MCPの登録後にツールが出ない場合は、設定画面のRestart等で読込を更新。Godotの外部変更通知は保存内容を確認して再読み込み。再インストールを最初の手段にしない。

12 / 実例 ③ 気持ちよさを足す

条件を決めると、表現が具体的になる。

左右入力 ＋ ジャンプ
人が伝えたこと｜授業用の要約
「左右を押してジャンプしたときだけ、
横滑りしながら曲がれるように」
Codexが変更したこと
開始条件と、着地後の滑りを追加。
Godotで確認すること
左右＋Spaceでドリフト。
Spaceだけなら普通のジャンプ。
後輪から小さな煙
人が伝えたこと｜授業用の要約
「ドリフト中、左右の後輪から
小さな白い煙を出して」
Codexが変更したこと
後輪の位置・煙の絵・出し方を追加。
Godotで確認すること
着地後に煙が出る。
普通のジャンプでは出ない。

実装ではドリフト開始は前進速度30%以上、煙は35%以上。初期の曲がりやすさ調整後、入力条件を明確にして再修正した記録があります。
